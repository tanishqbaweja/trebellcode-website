00What's new in 2.0

A major release.
Built around the agents you run.

Version 2.0.0 is the first major release since 1.6.0. It centers on the coding agents you run inside Trebell: Muse Code joins the lineup, OpenCode 2 is supported, and every harness now brings its own models, approvals, sign-in and updates. The interface is redesigned, every turn shows what it did, and the app is lighter on your machine.

NEW HARNESS

Muse Code joins the lineup

Meta's coding agent now runs inside Trebell. Sign in with muse login, and its replies, reasoning, commands and file edits stream into the thread. Its approvals and questions come to Trebell's own card and dialog, and Usage shows its 5-hour and weekly windows.

EVERY HARNESS

Its own models, its own updates

The model picker shows each harness's own models, options and default, and a reopened thread resumes on the model it used. Thinking shows as a collapsed Thinking row, OpenCode 2 runs beside OpenCode 1.x, and Settings offers an update when a harness has a newer release.

REDESIGNED

One design across the whole app

A redesigned interface with the same top bar on every page. Replies render as GitHub-style Markdown, with tables and code blocks you can copy.

VISIBLE WORK

Every turn shows what it did

Each turn keeps an activity card that says what every step did, such as a command's exit code and duration or an edit's diff. A turn that failed or was stopped before it replied says how and why.

TREBELL NATIVE

Streams, sees images, rides out network drops

On OpenAI, Native's replies stream in as they are written, and code-change turns are checked before the answer. Native can look at images in your workspace, and it waits for the network instead of failing the turn.

LIGHTER

Easier on your machine

Trebell starts fewer background processes, uses less CPU and GPU while you type and replies stream, and opens large threads with much less disk and database work.

03Why Trebell Native

The model is only half the system.
The harness changes the result.

The same capable model can behave very differently depending on the environment wrapped around it. Trebell Native is Trebell's own agent harness, built for the part a model vendor does not solve for you: the engineering system that turns inference into dependable repository work.

⌘01 / 03

Long tasks meet bad networks.

Dropped connections and rate limits are part of every long agent run. A harness that fails the turn throws the work away.

  • IN 2.0 When a model request cannot connect, Native waits for the network and tries again every 60 seconds until it gets through or you stop the turn.
  • IN 2.0 On a rate limit, Native waits as long as the provider suggests, and with OpenAI reasoning models a dropped connection no longer loses the turn's reasoning.
◇02 / 03

Agents operate in brittle worlds.

Files, terminals, Git, worktrees, credentials, processes, permissions and provider differences all become part of the agent’s actual runtime.

  • IN 2.0 Commands Native runs keep your project's toolchain variables, so Ruby, Rust, Java, Go and Python builds find their tools, locally and on remote hosts.
  • IN 2.0 Toolchain values that look like a password, secret, token or key are kept out of the commands Native runs.
✓03 / 03

Completion is not proof.

An agent saying “done” is not the same as the software being correct. Real engineering needs evidence, not confidence theater.

  • IN 2.0 Native recognizes more ways of asking for a code change and checks its work on those tasks before it answers.
  • IN 2.0 When its check cannot confirm the work, Native says why, and keeps or restores the version of your files the evidence best supports.
04Context

Give the model what matters.
Keep the rest retrievable.

Bigger prompts are not automatically better prompts. Trebell Native reads the files that define a name first, searches beyond source code, and keeps long output out of the model's way without losing it.

  • Definitions firstThe files that define a name are read before the files that only use it, and results come back grouped by file.
  • Beyond source filesCode search also finds matches in docs, templates, configuration and changelogs, and a search can be limited to a folder or a glob.
  • Long output, keptOn long tasks, runs of identical output lines are collapsed for the model, with the full output still retrievable.

05Efficiency

Optimize useful coding work.
Not vanity metrics.

Trebell measures the harness where it can actually control the result: what a finished task costs. On fresh tasks where Trebell Native and Codex using the OpenAI API got the same verifier result, Native's API-equivalent cost was 18% lower on SWE-bench Multilingual and 28% lower on Terminal-Bench 2.0. On Terminal-Bench Pro 1.0, cost was statistically level.

  • Same model & settingsgpt-6-luna with max reasoning on the fast service tier for both harnesses, with hosted web search off.
  • Same result firstCost is compared only on the tasks where both harnesses got the same verifier result.
  • 95% intervals0.75 to 0.90 on SWE-bench Multilingual and 0.58 to 0.87 on Terminal-Bench 2.0, from bootstrap resampling.

About Trebell.
Founder-led and product-first.

Trebell is a developer-tools startup founded in 2026. Its flagship product is Trebell Code, a free desktop workspace for AI-assisted software engineering, now at version 2.0. The company is founder-led and supported by a five-person core team.

Core product

Trebell Native is our own agent runtime and harness.

It runs its own model and tool loop, calling model APIs directly, with its own code search, permission modes, recovery and checks, instead of relaying everything through another coding harness.

Efficiency thesis

Inference should be spent on useful engineering work.

Repository retrieval, output virtualization, cache-stable context, stopping behavior and retry discipline are all places where a harness can reduce cost without asking the underlying model to become smarter.

Execution

The product already exists beyond the pitch.

Trebell Code 2.0 ships Trebell Native and runs seven more coding agents in one workspace with files, a terminal, Git and pull requests, worktrees, previews, a browser panel, projects and environments. Trebell Native's benchmark results are graded by an independent verifier.

Next milestone

Prove the pattern across more fresh software work.

Today's results come from 274 fresh tasks across SWE-bench Multilingual, Terminal-Bench 2.0 and Terminal-Bench Pro 1.0. The goal is repeatable harness gains across independent tasks, not one pretty benchmark.

Position

Provider-independent, but not dependent on somebody else’s harness.

Trebell Native calls model providers directly, with OpenAI as the default, while Trebell Code also runs seven other coding agents as their real harnesses. That keeps model choice separate from the engineering system we are actually building.

Team layer

The same harness becomes more valuable when usage is shared.

The planned commercial layer adds organization policy, shared usage and cost controls, managed execution environments, auditability and administration without changing the underlying developer workflow.

Business model

Free for developers. Paid infrastructure for teams.

Trebell Code is free and Apache-2.0 licensed, and individual developers can adopt it directly. Trebell's planned commercial layer adds organization policy, shared usage and cost controls, managed execution environments, auditability and administration for engineering teams.
