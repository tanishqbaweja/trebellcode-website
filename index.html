Company

Trebell builds the layer around the model.

Trebell is an independent developer-tools company focused on making AI coding systems more useful on real software projects. Trebell Code is developed and maintained by Trebell and is our primary product. Instead of locking developers to one model vendor, Trebell Code provides a common desktop workspace for multiple coding runtimes and model providers, then adds the context management, tools, recovery and verification needed to finish engineering work reliably.

Product

A complete coding workspace

Repository context, terminal execution, file editing, Git and worktrees, browser automation, project recovery and evidence live in one harness.

Users

Built for software developers

Trebell Code is for developers who want coding agents to work on real codebases without giving up provider choice or visibility into what the agent did.

Approach

Provider-agnostic by design

The harness can work across multiple agent runtimes and model providers, so the workflow is not tied to a single AI vendor.

Proof

Measure the finished result

We benchmark correctness and actual dollar cost on software-engineering tasks, with builds, tests and browser evidence rather than treating token count alone as success.

Trebell Code

trebell / code
LIVE · v1.3.6APACHE-2.0
Trebell's flagship open-source AI coding harness.

Trebell Code is developed by Trebell as a desktop workspace for agentic software engineering. It owns the orchestration layer between AI models and real projects: repository context, tools, terminals, Git worktrees, browser automation, recovery, persistence and verification. Developers can switch between supported coding runtimes and model providers without rebuilding their entire workflow around one vendor.

  • One desktop harness for coding agents, terminals, files, Git, browser automation and project context
  • Provider-agnostic architecture with multiple agent runtimes and model providers
  • Terminal-Bench 4.0: 4/4 vs Codex API 4/4 at 28.6% lower cost
  • Same-outcome 3/4 run: 90.7% cheaper than Codex API, 80.5% cheaper than OAuth

  • Evidence-first verification through tests, builds, browser runs and screenshots
