Trebell Code

Trebell is a small company that makes tools for software developers. Our main product, Trebell Code, is a free desktop app for working with AI coding agents: Trebell Native, our own agent, plus Codex, Claude Code, OpenCode, Cursor, Grok Build, Antigravity and Muse Code. They work in your real repositories, with a terminal, Git and a browser panel, and we measure whether the finished work is correct and what it cost.

We make AI coding agents useful on real code.

We are an independent developer-tools company. We build and maintain Trebell Code, our main product. It gives you one desktop workspace for several coding agents and model providers, so you are not tied to one vendor, and it adds the context handling, tools, recovery and checks that help an agent finish the job properly.

The workspace

Repository context, a terminal, file editing, Git and pull requests, worktrees, previews and a browser panel, in one desktop app, around whichever coding agent you use.

Built for software developers

Developers who want coding agents working on real codebases, without giving up their choice of provider or the ability to see what the agent did.

Works with many providers

Trebell Code works with several agent runtimes and model providers, so your setup does not depend on a single AI company.

We measure finished work

We count resolved tasks and API cost on fresh software-engineering tasks, graded by an independent verifier, instead of treating a low token count as success.

What we make

Trebell Code is our main product, now at version 2.0. We also make PDFOmni, a PDF editor that runs in your browser.

Trebell Code

Version 2.0.0Apache-2.0
A desktop workspace for AI coding agents.

Version 2.0 runs Trebell Native, our own agent harness, beside Codex, Claude Code, OpenCode, Cursor, Grok Build, Antigravity and the new Muse Code. Each one runs as its real harness, with its own models, sign-in and approvals. Around them are your files, a terminal, Git and pull requests, worktrees, previews and a browser panel, so you can switch agents without rebuilding your workflow.

  • One desktop workspace for coding agents, files, terminal, Git and pull requests, previews and a browser panel
  • Eight harnesses, including Muse Code and OpenCode 2, new in 2.0
  • SWE-bench Multilingual, 156 fresh tasks: Trebell Native resolved 125, Codex using the OpenAI API 124, at 18% lower cost on same-result tasks
  • Terminal-Bench 2.0, 78 fresh tasks: 62 resolved each, at 28% lower cost on same-result tasks
  • Terminal-Bench Pro 1.0, 40 fresh tasks: 22 resolved, against 21 for Codex using the OpenAI API
  • Every turn shows what it did: a command's exit code and duration, an edit's diff
