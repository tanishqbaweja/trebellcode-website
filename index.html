Company

Trebell builds the layer around the model.

Trebell is an independent developer-tools company focused on making AI coding systems more useful on real software projects. Trebell Code is developed and maintained by Trebell and is our primary product. Instead of locking developers to one model vendor, Trebell Code provides a common desktop workspace for multiple coding runtimes and model providers, then adds the context management, tools, recovery and verification needed to finish engineering work reliably.

Product

A complete coding workspace

Repository context, a terminal, file editing, Git and pull requests, worktrees, previews and a browser panel live in one desktop workspace, around every coding agent you run.

Users

Built for software developers

Trebell Code is for developers who want coding agents to work on real codebases without giving up provider choice or visibility into what the agent did.

Approach

Provider-agnostic by design

The harness can work across multiple agent runtimes and model providers, so the workflow is not tied to a single AI vendor.

Proof

Measure the finished result

We benchmark resolved tasks and API cost on fresh software-engineering tasks, graded by an independent verifier, rather than treating token count alone as success.

Trebell Code

code.trebell.dev
LIVE · v2.0.0APACHE-2.0
Trebell's flagship desktop workspace for AI coding agents.

Trebell Code is developed by Trebell as a desktop workspace for agentic software engineering. Version 2.0 runs Trebell Native, Trebell's own agent harness, beside Codex, Claude Code, OpenCode, Cursor, Grok Build, Antigravity and the new Muse Code, each as its real harness with its own models, sign-in and approvals. Around them sit files, a terminal, Git and pull requests, worktrees, previews and a browser panel, so developers can switch agents without rebuilding their workflow around one vendor.

  • One desktop workspace for coding agents, files, terminal, Git and pull requests, previews and a browser panel
  • Eight harnesses, including Muse Code and OpenCode 2, new in 2.0
  • SWE-bench Multilingual, 156 fresh tasks: Trebell Native resolved 125, Codex using the OpenAI API 124, at 18% lower cost on same-result tasks
  • Terminal-Bench 2.0, 78 fresh tasks: 62 resolved each, at 28% lower cost on same-result tasks
  • Terminal-Bench Pro 1.0, 40 fresh tasks: 22 resolved, against 21 for Codex using the OpenAI API
  • Every turn shows what it did: a command's exit code and duration, an edit's diff
