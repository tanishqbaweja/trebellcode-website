Releases

Published release notes

Releases from 2.0.0 on are published with their release notes in Trebell Code's public releases repository. Version 2.0.0 is the first major release since 1.6.0.

Updates

You choose when to update

From 2.0.0 on, Trebell Code checks the public releases repository for new versions. An update downloads and installs only when you choose.

Installing

Clear terms for a tool that works on your code.

A coding workspace works with your repositories, terminals, Git and model accounts, so its terms should be simple: a free app under the Apache License 2.0, versioned releases with published notes, and updates that install only when you choose. The 2.0.0 installer is not code-signed yet, so Windows SmartScreen may ask you to confirm it: choose More info, then Run anyway.
